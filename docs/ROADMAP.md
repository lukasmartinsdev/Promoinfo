# Próxima etapa: Supabase

A integração futura deverá substituir gradualmente o `localStorage` por:

- Supabase Auth para usuários, administradores e lojistas;
- PostgreSQL do Supabase para produtos, ofertas, lojas, marcas e permissões;
- Supabase Storage para imagens e logos;
- regras de acesso com Row Level Security;
- sincronização com o frontend atual sem alteração visual.

Nenhuma integração foi ativada nesta versão.
